# SMAP 发布说明

## 1.2.0

1.2.0 于 2026-11-10 发布，对应 Git 标签 `1.2.0`。

### 改进与优化

1.支持运行期NUMA节点上限：用户态和内核态都适配了运行期的NUMA cap，节点位图和迁移相关的矩阵改为运行期管理；远端NUMA节点校验也统一按运行期上限执行
2.扩展4K虚机扫描与迁移支持：新增4K VM的扫描、迁移路径，并补充对应的swap策略配置；4K VM暂不支持统计扫描与HAM扫描
3.新增按进程内核换出能力：增加per-pid内核swap-out核心逻辑和swap配置传递，并加入L3冷周期统计，与换出策略集成

### 公共接口

当前公开接口以 `src/user/smap_interface.h` 为准，包含生命周期、迁出/迁回、进程跟踪、查询和远端
NUMA 迁移能力。详细清单见 [API 参考](api_reference.md)。

### 兼容性

- aarch64 Linux/openEuler。
- 用户态库、内核模块、运行内核和内核开发包必须配套。
- 支持虚机模式（2M 大页或 4K）与进程模式（4K）。启动时二选一，不能在同一实例混用。
