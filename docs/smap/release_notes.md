# SMAP 发布说明

## 1.1.2

1.1.2 于 2026-11-2 发布，对应 Git 标签 `1.1.2`（commit `3c7c5d7e72fd4deaaf39fad796d203b9562508b8`）。

### 改进与优化

1、新增HotScan工具配套解析报告SKILL
2、支持工具配置进程扫描周期&迁移周期
3、启动迁出消息指定源本地NUMA节点
4、借鉴 HybridTier (ASPLOS'25) 双指标模型，为 SMAP 增加跨窗口累计访问频次 acc，用于区分“长期持续热”与“短期瞬时热”页面，并把累计热度与本轮频次一起用于迁移选页，提升热页/冷页识别精度。

### 公共接口

当前公开接口以 `src/user/smap_interface.h` 为准，包含生命周期、迁出/迁回、进程跟踪、查询和远端
NUMA 迁移能力。详细清单见 [API 参考](api_reference.md)。

### 兼容性

- aarch64 Linux/openEuler。
- 用户态库、内核模块、运行内核和内核开发包必须配套。
- 4K 普通进程与 2M 静态大页虚机在启动时选择，不能在同一实例混用。
