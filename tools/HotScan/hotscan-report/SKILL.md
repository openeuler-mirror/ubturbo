# HotScan 热区图分析报告技能

## 触发条件

当用户要求：
- 根据 HotScan 的热区图出具分析报告
- "热区图怎么看"、"这批图说明了什么"、"出一份分析报告"
- **"根据报告/图给出建议的扫描周期和迁移周期"、"这部分配多少合适"** → 报告正文"建议做什么"必须带配置参数建议表，推导走 Step 4.5
- 复核已有分析报告的结论与口径

## 概述

HotScan 是内核态页访问探针（`tools/HotScan/`），每轮读取并清除 PTE Access Flag，产出 `scan_<n>.out` 二进制序列；`hotplot.ActcPlot` 把这些序列画成热区图并模拟迁移策略。本技能把"**热区图 → 结构化中文报告**"固化成固定流程，**核心是图表语义解读、指标口径声明、图表可支撑结论的边界，以及把结论落成可用的 SMAP 配置参数建议（Step 4.5）**。

路径约定：下文 `<HS>` 表示 `tools/HotScan`；若需要从扫描数据现算指标或绘图，脚本必须在 **Linux + numpy + matplotlib** 环境执行（模块编译与采集也只在 Linux/aarch64 可用）。

## 输入契约（先确认拿到了什么）

本技能的**必需输入是热区图（可视化图表）**，不是扫描数据。报告只写图能支撑的结论；扫描数据是**可选**输入，有它才能升级为定量报告。

| 输入 | 必需 | 说明 / 缺失时的处理 |
|---|---|---|
| **热区图（PNG 等图片）** | **是** | 至少要有"逐轮热页数 / 热区生命周期"类图；没有图就没有报告对象。**图模式报告必须包含热区生命周期图**（`plot_lifetime_hot_zone_sorted.png` 必备、未排序版推荐）——缺这张图时先按 Step 3.3 补生成，再动手写报告 |
| 图注 / 随图说明（批次、进程、采集周期、轮次范围） | 否 | 缺什么写「未提供」；横轴若只给轮号，不得自行换算成时间 |
| 扫描数据 `scan_*.out` | 否 | **有** → 可跑 Step 1 定量门禁、Step 1.1 自动分段、Step 3 精确计数；**无** → 全部降级为定性描述 |
| 指标 JSON | 否 | 同上，按"有数据"处理 |
| 模块参数 / 被观测进程与版本 | 否 | 记「未提供」，不得猜测 |
| 加压/激励命令与相位时序 | 否 | 用 Step 1.1 分平台；**严禁**凭曲线形状反推负载语义（不能写"这段是 SET、那段是 GET"） |
| 激励源码 / 真值 / 期望集合 | 否 | 缺失即按 C 类处理，P2 / P6 判「不适用」 |

两类报告，开写前先选定：

| 模式 | 输入 | 报告能力 |
|---|---|---|
| **图模式（默认）** | 只有热区图 | 定性：曲线形态、平台结构、集中度形态、策略趋势。**不得出现精确计数**；引用数值必须标注出处——单格图标题/图例里的现成数字标「读图（图内标签）」，曲线目视读数标「读图估计」，两者都不等于实测 |
| **数据模式** | 热区图 + `scan_*.out` 或指标 JSON | 定量：门禁 P1–P7、精确计数、逐段统计表 |

原则：**只分析输入能支撑的结论**。凡是靠外部信息才能填的字段，逐项标注来源（图读出 / 数据算出 / 操作者提供 / 未提供）；未提供就写"未提供"，不填推测值。**图模式只承认图内信息**：采集参数、被观测进程、激励时序若没有随图提供，即便操作者本人知道，也一律写「未提供」，不得用记忆补全。

## Step 0.5: 读者定位与表达规范（报告要交给客户时必做）

**默认按"客户版"写**：读者懂服务器/虚拟化，但不懂 SMAP 内部实现，也不看源码、不跑命令。技术严谨性一条不能少，但**表述必须能被非专家读懂并复述**。

### 结构：双层

| 层 | 位置 | 写什么 |
|---|---|---|
| 客户层 | 正文 | 结论、"这说明什么"、"对您的影响"、可执行建议。不出现代码、命令、内部路径 |
| 工程层 | 附录 | 术语表、口径定义、复现命令、自检明细、激励源码、数据文件清单 |

正文第 1 节固定三块，缺一不可：**一句话结论**（≤ 60 字）+ **三条要点**（每条 ≤ 80 字，一到两句完整句子）+ **建议做什么**（谁、做什么、验收标准）。

结论摘要只写结论，不写定义：三条要点固定为"覆盖 / 频次 / 分布或策略"，术语与计数定义放正文第 2 节和附录 B/C。

### 术语：首次出现必须白话解释

正文尽量用白话，不引入未解释的缩写；必须出现术语时给 ≤ 10 字的极短注释，完整定义放附录 C 术语表。参考句式：

- SMAP（把进程内存按 NUMA 节点分配、并决定哪些页要搬到"本地"的调度插件）
- 热区（一段时间内被反复访问的一批内存页）
- 访问标记（CPU 每访问一页会自动打的"已访问"记号；插件每轮读取后清零）
- 迁移（把一页内存从当前节点搬到另一个节点）
- 本地/远程（访问自己节点内存为"本地"，跨节点为"远程"，远程访问更慢）

### 内部话 → 客户话（对照表）

| 内部表述 | 正文写法 | 允许出现的位置 |
|---|---|---|
| `[63:48]` 布尔标记、PTE AF | "访问标记（每轮只回答'碰过没有'）" | 附录口径 |
| `local_ratio` 假设、zic 策略模拟 | "按'本地能放多少页'做的模拟，不是实测硬件分布" | 正文需带这句限定 |
| P1–P7、门禁 | "7 项自检" | 正文首次给中文名，编号放附录 |
| 精确率 / 召回率 | "漏报 / 误报"（括号附原词） | 正文 |
| `saturated` / `resolvable` | "满格 / 可分辨" | 正文 |
| 页次 | "页·轮（一页在一轮里被记一次）" | 正文首次 |

### 数字：必须带参照物

- 小比例要给"多少次里约 1 次"，并写成完整短句：`0.04%` → "平均每 2500 页·轮出现 1 次"；不要写"约 10 页 1 页"这类省略式。
- 大比例要给绝对量：`97.5%` → "前一半页承担了几乎全部访问（120 轮合计）"。
- 百分点差要说明基数：`+15.6 pp` → "命中率从 77% 升到 93%"。
- 不给无参照的秒/毫秒堆叠；先给结论，再给范围与前提。

### 图：每张图配"怎么看"

三行固定：① 横轴/纵轴各是什么（白话）；② 该看什么形状（台阶、平台、空档）；③ 最容易被误读的一点。图标题里的指标（如 "75% hit ratio"）若属弱指标，要明说"这个数不用看"。

### 结论：翻译成决策

每条技术结论后跟一句"**这意味着**"：影响谁、要不要动作、不动作会怎样。建议必须可执行（谁 / 做什么 / 怎么验收），参数名可用，但要在括号里，并用白话说明这个参数管什么。

### 底线

- 通俗**不得改变结论口径**：图模式不得出现精确计数、数据模式不得把模拟说成实测、缺失对照仍要写"未提供"。
- 类比必须标"打个比方"，且不得替代事实描述。
- 正文不拿内部文件路径、命令、代码当论据；这些一律下沉附录。
- **报告成品不标注"客户版"**：该词只用于内部说明写作口径，标题、副标题与正文均不出现；只在标题括号里保留"数据模式 / 图模式"等模式标识。

## Step 0: 识别数据来源形态（决定适用哪些判据）

| 形态 | 特征 | 可用的强判据 | 采集/复现脚本 |
|---|---|---|---|
| **A. 高斯归档** | 有 `truth.csv` 逐页真实触碰次数 | 逐页 Pearson 相关系数、峰值落位、相位均值 | `<HS>/tests/analyze_gaussian_run.py`、`tests/gaussian_va_stimulus.c` |
| **B. 矩形热区** | 只有期望热区集合，无逐页次数 | 逐轮精确率/召回率、静默期误报数 | `<HS>/tests/verify_hot_regions.py`、`tests/hot_region_stimulus.c` |
| **C. 通用采集** | 无真值、无期望集合 | 只能做质量门禁 + 集中度 + 策略模拟 | `parse_smap.py` |

**先问清楚（或从激励源码 / 随图说明确认）是哪一类**，否则会写出无法证伪的结论。**图模式默认按 C 处理**（图片无法判定是否有真值）；拿不到激励源码 / 加压命令时同样按 C 处理，并在报告中显式声明"无真值，结论为描述性统计"。

A/B 类的强判据（逐页相关系数、逐轮精确率/召回率）都以**激励源码里的定义**为前提。拿不到源码时这些判据不可复现，属于"伪装成 A/B 的 C 类"，不要硬套。

## Step 1: 质量核验（必须最先做，不通过则停止）

**有扫描数据（数据模式）**：逐项跑下面的 P1–P7 门禁，结果写进报告正文第 2 节。**只有热区图（图模式）**：跑 P0 图可读性检查，并在正文第 2 节**显式声明**"未做数据级门禁，全文结论为定性描述"。

| 编号 | 判定项 | 判据 | 核验方式 |
|---|---|---|---|
| P0 | 图可读性（图模式必做） | 坐标轴有标签与单位、图例/图注完整、轮次或时间范围明确、无明显截断（如曲线在边缘被切断）；**多面板大图（高 > 8000 px）不得直接判读**，须按面板行分片后再判读（见 Step 3.6） | 目视 + 图注；缺哪项就在报告中声明 |
| P1 | 轮次完整性 | `scan_<n>.out` 编号连续无缺 | 目录列表 + 首尾编号 |
| P2 | 目标页覆盖 | 每轮目标页全命中（如 256/256） | 脚本内断言 |
| P3 | VA 唯一性 | 同轮无重复 VA | `unique(va).size == raw.size` |
| P4 | 编码合法性 | `[63:48] ≤ 1`，且 `(entry & 0xfff) == 0x100`（bit8=1、bit9~11=0、低 8 位=0） | 逐条位断言 |
| P5 | 解码一致性 | 独立 `struct.iter_unpack` 解码结果与解析器一致 | A/B 类由既有脚本覆盖 |
| P6 | 热区保真 | A：r>0.95；B：精确率/召回率=1.0 | 见 Step 3 |
| P7 | 无污染 | 静默阶段访问标记≈0 | 相位窗口统计 |

```bash
# 以下命令均为数据模式（需要扫描数据）；图模式跳过本节
# A 类：一次跑完全部断言 + 绘图 + 指标 JSON（必须在 <HS> 下执行，默认路径是相对路径）
cd <HS> && python3 tests/analyze_gaussian_run.py tests/artifacts/hotscan-gaussian-20260929.tar.gz
# B 类：独立解码 + 期望集合校验
python3 tests/verify_hot_regions.py /tmp/verify 0x<BASE_VA> \
    --phase-a 5:35 --phase-b 45:75 --idle 85:105 --max-noise 0
```

两处易错点：

- `0x<BASE_VA>` 是激励程序映射区的起始 VA。B 类由激励 stdout 打印（`base=0x...`）；A 类归档里存在 `run.log` 的 `base=` 字段，`analyze_gaussian_run.py` 已自动解析，无需手填。
- 相位窗口 `5:35 / 45:75 / 85:105` **只对当前激励时序成立**（100 ms 采集周期 + 每相位 4 s sleep）。换激励脚本或改 sleep 节奏后必须重算：取各相位的稳定区间，掐掉切换前后若干轮（本例各掐 5 轮，即 500 ms）。窗口取错会把切换期误判成"漏检"。
- 拿不到激励时序时，**不要**跳过本节、也**不要**拍脑袋写窗口：改走 Step 1.1 的数据驱动分段，P7 相应降级为"分段内自洽性检查"。

### Step 1.1 相位/工况分段（无激励时序时的替代做法）

目标：把采集期切成若干**工况段**，段名用中性标签（如 `initial_burst` / `active_plateau` / `idle_plateau`），**不断言负载语义**。

- **数据模式**：用逐轮被标记页数 `actc.sum(axis=1)` 做下面的自动分段。
- **图模式**：在"逐轮热页数"图上**目视读**平台边界，写成"约第 25 轮、约第 400 轮"这样的估计值，并在报告中标注「读图估计」；不要反过来声称做过自动分段。

三步，灵敏度用数据自身的噪声标定，避免拍参数：

```python
hot = actc.sum(axis=1).astype(float)
dd = np.diff(hot)
sigma = 1.4826 * np.median(np.abs(dd - np.median(dd))) / np.sqrt(2)   # 逐轮噪声尺度
K, MINLEN, REL, TRIM = 5.0, 20, 0.10, 0.20

# (1) 二分段：递归找最优分裂点，接受条件 |Δmean| > K*sigma*sqrt(1/n1+1/n2)，且每段 ≥ MINLEN 轮
# (2) 合并：相邻段均值相对差 < REL 就合并，把同水平的碎段并回平台
# (3) 修剪：从段两端剔除偏离段中位数 > TRIM 的轮，记入"过渡/异常轮"单列
```

要点：

- **不要只用一次分段**：小 K 会把噪声当拐点切成十几段（正常噪声 5 页量级即可切出 12 段），必须靠相对差异合并回平台，否则段数不可用。
- **必须保留"过渡/异常轮"**：被修剪掉的轮往往正是最有价值的信号（首轮 Access Flag 残留、写入峰值冲高等），要在报告里单列，不能悄悄丢掉。
- **段内并集不可跨段直接比大小**：观测轮数不同，页并集天然随轮数增长；要么按轮数归一，要么只在等长窗口上比。
- 段名是**位置标签**，不是负载标签。想写"写路径/读路径"必须另有证据（操作者提供、或标记数与迁移量的对照），否则只能写"高平台段 / 低平台段"。

任一项不通过：**不要出报告**，先回报失败项并提议重新采集。

## Step 2: 指标计算口径（写进报告前必须核对）

这些口径错误会让报告结论直接反转，逐条落实：

| 口径 | 正确表述 | 常见错误 |
|---|---|---|
| 访问语义 | `[63:48]` 是**布尔量**（该轮是否访问过），多触碰合并为 1 | 当成访问次数做定量结论 |
| 访问总数 | 必须注明口径：轮次范围 × 页集合 | 把"全部轮次全部页"与"去前 5 轮仅目标页"混用对比 |
| `[11:8]` 位 | 恒为 `HOTSCAN_NUMA_LOCAL`（bit8 置位，即 `(entry & 0xfff) == 0x100`），**不是 NUMA 站点** | 当成 local/remote 实测结果 |
| `local_ratio` | 是**策略模拟假设**，不是测得的内存分布 | 写成"本地命中率实测为 XX%" |
| `avg_hit` | `plot_actc_sorted_partition()` 返回的是**百分数**（如 96.14），覆盖全部周期 | 当成 0~1 比例二次乘除 |
| 汇总口径差异 | `_print_cycle_stats()` 打印的汇总行会**去掉前 2 轮与最后 1 轮**，与返回的 `avg_hit` 不同口径 | 两者混用却不注明 |
| lifetime 横轴 | 未排序图是"已观察页按 VA 排序后的索引"，跨映射段间距无物理含义 | 当成连续 VA 或页号 |
| lifetime 频次单位 | 纵轴 Access count 是**原始扫描轮**中的命中轮数（总轮数 = 周期数 × 合并步长，不随面板数缩水）；不是合并后的周期数，也不是访问次数 | 把 27 次当成 27 个周期，或拿它与 9 个面板数对比 |
| lifetime 聚合与上限 | lifetime 图把**全部轮次（含预热段）聚合成一条曲线**；纵轴上限由 p99 频次自动截断（约为 p99 的 1.1 倍） | 拿顶格饱和的 y 值比较页间热度，或以为它反映单一相位 |
| 集中度 | 用"前 N% 页 → 覆盖访问占比"曲线 | 引用图标题里的 "75% hit ratio"（降序排列必然接近 100%，是弱指标） |
| 分段标签 | 数据驱动分段的段名是**位置标签**，不是负载语义 | 写成"这段是 SET / 那段是 GET" |
| 跨段并集 | 并集随观测轮数增长，须按轮数归一或只用等长窗口比较 | 直接比不同长度段的 `hot_union` 大小并下结论 |
| 外部字段来源 | 环境/负载字段逐项标注 数据自带 / 数据推断 / 操作者提供 / 未提供 | 把"未提供"的字段当已知事实写进报告 |

## Step 3: 取数与作图（仅数据模式；图模式请直接跳到 Step 4）

> 本节内容以扫描数据可用为前提。图模式下拿不到 `actc` 矩阵，**不要**照抄下面的代码，也不要凭图"反算"出这些量；直接进入 Step 4，只做定性解读与图间交叉印证。

### 3.1 读扫描数据

```python
import sys; sys.path.insert(0, '<HS>')
from parse_smap import parse_raw_smap_pte_file

# 返回 5 项；actc 是 0/1 二值 (cycles, pages)
actc, page_masks, local_masks, interest_mask, unique_va = parse_raw_smap_pte_file('/tmp/tag/scan_*.out')
# local_masks 由已被硬编码为 1 的 [11:8] 位生成，**在设计里被丢弃**，不要用它做 local/remote 划分
```

另有 `parse_raw_smap_files(path, make_cache=True)` 返回 4 项（无 `unique_va`）并缓存 `.npz`；`page_masks` 是逐周期的页存在掩码（`cycles × pages`）。

**定位目标映射的页索引（后面所有"按页号"的图和指标的前提）**：`actc`/`page_masks` 的列空间是"全局去重 VA"（含进程的其他映射），不是激励目标映射的页号。必须用 base VA 反查列下标，否则横轴与页号对不上：

```python
unique_va = np.asarray(unique_va)      # data_normalize() 用 sorted() 生成，保证升序
PAGE, PAGES = 4096, 256                # 必须与激励的 page_size / 目标映射页数一致
target_vas = np.uint64(BASE_VA) + np.arange(PAGES, dtype=np.uint64) * PAGE
idx = np.searchsorted(unique_va, target_vas)
assert (unique_va[idx] == target_vas).all(), '目标页未全部出现在扫描结果中'
actc_target = actc[:, idx]             # (cycles, 256)，列 i 对应映射内第 i 页
masks_target = page_masks[:, idx]
```

若同时要看"目标映射在全进程中的位置"，就保留全量矩阵，只在画图时用 `idx` 切出子集（`img/.../target_mapping/` 那类图），并在图注里写明横轴含义。

```python
import numpy as np, matplotlib; matplotlib.use('Agg')
import matplotlib.pyplot as plt
from hotplot import ActcPlot

# (1) 集中度曲线：横轴前 N% 页，纵轴累计访问占比
def concentration(total):                      # total = actc.sum(axis=0)
    ordered = np.sort(total)[::-1]
    return np.cumsum(ordered) / ordered.sum()
# 报告里固定给 top10% / top25% / top50% 三个点，别只给曲线

# (2) zic 策略扫描：逐周期命中率 + 容量扫描（无图模式下取数）
def capture_cycle_stats(actc, page_masks, ratio, img_dir):
    cap, orig = {}, ActcPlot._print_cycle_stats
    ActcPlot._print_cycle_stats = lambda self, stats, avg, mig: cap.update(
        stats=stats, avg_hit=avg, total_migrate=mig)
    try:
        ActcPlot(actc, img_dir, page_masks=page_masks,
                 local_ratio=ratio, plot=False, policy='zic').plot_actc_sorted_partition()
    finally:
        ActcPlot._print_cycle_stats = orig
    return cap          # cap['stats'][i]['local_hit_ratio' / 'nr_migrate' / 'demote' / 'promote']
# 容量网格建议 [0.10,0.20,0.30,0.40,0.50,0.60,0.75,0.90]，
# 同时记录 avg_hit（百分数）与 每轮迁移 = total_migrate / cycles

# (3) 逐轮精确率/召回率（B 类数据的 P6/P7 判据，输入必须是 actc_target）
HOT_A = set(range(16, 48)) | set(range(96, 128))     # 必须与激励源码里的热区定义一致
HOT_B = set(range(160, 192)) | set(range(224, 256))

def per_round_scores(actc_target, phase_of_round, expected_sets):
    """phase_of_round: 长度 = 轮数，元素是相位 id；-1 表示切换/未归类，跳过。
       expected_sets: {相位 id: 该相位的期望热页索引集合}，静默相位填 set()。
       返回 [(轮号, precision, recall)]。"""
    scores = []
    for i, phase in enumerate(phase_of_round):
        if phase < 0:
            continue
        detected = {int(p) for p in np.nonzero(actc_target[i])[0]}
        expected = expected_sets[phase]
        if expected:
            hit = len(detected & expected)
            scores.append((i, hit / len(detected) if detected else 0.0, hit / len(expected)))
        else:
            # 静默相位：期望空集，"无热页"才是正确，精确率与召回率同义
            clean = 1.0 if not detected else 0.0
            scores.append((i, clean, clean))
    return scores
# 报告里引用 min(precision) / min(recall) 与静默期误报总数，不要只给平均值
```

### 3.6 大图分片与单格放大（多面板图必做）

`plot_hot_region*.png`、`plot_actc_sorted_partition.png` 的尺寸是 `35 in × 网格行数×5 in`（120 轮 → 3500×15500 px），整张不可读；**按 20 行分片后仍读不清单格标题**。固定分三层：

- 必须按面板行边界裁切，**不能按等分像素高度切**（会切断面板）；用与绘图相同的 `GridSpec(ROWS, COLS, wspace=0.2, hspace=0.3)` 反推每个 axes 的 `get_position()`，乘图高得到行顶。

- 命名：`<原图名>_slice<k>_rows<a>-<b>.png`、`panel_zoom_<含义>.png`；单格拼图要在正文写清「自上而下依次是哪些 cycle」。
- 分片后读不清标题是**正常现象**，不要从缩略图猜数；正文第 2 节显式写出可读性边界（段级可读 / 单格可读）。

for i, a in enumerate(ax):

## Step 4.5: 由分析结果推导配置参数（报告正文"建议做什么"必写）

用户问得最多的往往不是"图说明了什么"，而是"**扫描周期和迁移周期该配多少**"。本节把"读数 → 参数"的推导固定下来，**禁止从曲线形状直接跳到一个毫秒数**。

### 4.5.1 先查工程约束（这些是事实，不是建议）

| 项 | 值 | 出处 |
|---|---|---|
| `smap.scan.period` 默认 / 范围 / 粒度 | 200 ms / **[50, 60000]** / 50 ms | `strategy_config.h`：`DEFAULT_SCAN_PERIOD`、`MIN/MAX_SCAN_PERIOD`；`device.h`：`SCAN_PERIOD_UNIT_MS` |
| `smap.migrate.period` 默认 / 范围 | 2000 ms / **[500, 300000]** | `strategy_config.h`：`DEFAULT/MIN/MAX_MIGRATE_PERIOD` |
| 硬约束 | `scanPeriod > migratePeriod` 直接判错、启动失败（即须 `P ≤ M`） | `strategy_config.c` `StrategyConfigReview()` |
| M/P 上限 | 6000（= `MAX_MIGRATE_PERIOD / MIN_SCAN_PERIOD`） | `strategy_config.c` `MAX_SLOW_THRESHOLD` |
| freq 物理上限 | 一个迁移周期内逐轮布尔累加 ⇒ **freq ≤ M/P** | 采集语义（访问标记是布尔量） |

**任何建议值都必须落进上面两张范围表且满足 `M ≥ P`；越界的建议等于让用户启动失败。**

### 4.5.2 推导扫描周期 P

唯一链条：`p = 1 − exp(−λP)` ⇒ 可测速率窗 **λ ∈ [0.05/P, 3/P]**。

1. **算窗**：取 `3/P` 高于目标负载热页的真实访问速率、`0.05/P` 低于其冷页速率的最小 P。
2. **看实测**：多 P 对照时，比较同一 `p` 阈值下的 `saturated` / `resolvable` 页数（`window_stats`）。**P 变小应使 `saturated` 明显下降、`resolvable` 明显上升**；若两者都不动，说明热页速率已双双落在窗外，继续缩 P 无收益。
3. **验预算**：P 的下界由"一次页表遍历耗时"决定。必须用 `frac(dt > 1.5P) == 0` 且「轮数 = 时长 / P」证明**没有跳轮** —— 跳轮等价于有效 P 翻倍，此时一切分辨率结论作废。
4. **给值**：
   - 有实测且无跳轮 → 给**可复现的最小值**（从配置下限 50 ms 起算），并写明"一旦出现跳轮就退到下一档（50 → 100 ms）"的条件；
   - 只有单 P 数据 → 只给**方向 + 替代判据**（"P 应取到使 `3/P` 覆盖热页速率"），并列出还缺哪组对照才能定值；
   - **只有图（图模式）→ 一律只给定性方向，不得给毫秒数。**
   - 图模式特例：若逐轮标题已**每轮饱和**（如稳态 `64/64`、切换轮 `136/268`），说明触碰密度高于扫描频率，图对 P 完全不敏感 —— 此时要写明"本批图无法支撑 P 的定量，连方向也需多档 P 对照才能确定"，不要用满格的图当"P 合适"的证据。

**不要**用"逐轮被标记页数"比较 P 的优劣 —— 它随 P 单调上升纯粹是窗口积分效应，不是质量指标。

### 4.5.3 推导迁移周期 M

M 是"迁移带宽 ↔ 反应速度"旋钮，**稳态下命中率对 M 基本不敏感**。三步：

1. **先去掉容量混淆**：`local_ratio` 口径下"容量 = 比例 × 窗口内被触碰页数"，窗口随 M 变长 ⇒ 容量被放大 ⇒ 命中率虚高。**凡涉及 M 的结论都必须用固定本地容量 K 复算**（固定 K / `local_mask_preset`），否则结论可能整体反转（实测同一份数据会从"命中率随 M 单调上升 11.6pp"翻转成"命中率平坦 ±1.1pp"）。
2. **两个方向各取一个判据**：
   - 稳态：看**迁移量随 M 的下降曲线**，取"再放大 M 收益已趋缓"的拐点（`迁移页/s` 降幅明显变小处）。
   - 阶跃：看**命中率与 oracle 上界的 gap**，取"gap 仍小于容忍值（建议 2pp）"的最大 M。
3. **给值**：用**倍数**表达 `M = k·P`，k 取上面两个判据的公共区间（Redis 阶梯负载实测落在 **k ∈ [16, 32]**），再换算成毫秒并复核范围与 `M ≥ P`。

**两个额外约束**：

- `freq ≤ M/P`：k 太小（< 8）时 freq 只剩个位数，排序被单轮噪声主导 —— 这是 k 不该取 1–4 的原因之一。
- 必须**同时给出区间与取舍条件**（例如"平稳负载取上沿 / 热集频繁阶跃取下沿"），只给一个数一定会被误用。

### 4.5.4 报告里必须写成的形式

**表格：参数 | 建议值 | 依据（引用图/JSON/脚本输出）| 前提与置信度**

- 建议值一律写成"区间 + 上/下沿的适用条件"，并与默认值做对比（默认 200/2000 是否够用、**主要该改哪一个**）。
- 每个值后面必须挂一句**外推限制**：本批的页规模/轮数/实例数不可外推，应把 `M = k·P` 的**倍数**迁移到生产规模后复验，而非照搬毫秒数。
- 调优顺序写进结论：**先定容量 → 再定 M → 最后把 P 压到遍历预算允许的最小值**。

### 4.5.5 禁止事项

1. 不得用 `local_ratio` 口径的结果给 M 定值。
2. 不得给出范围外、或 `M < P` 的裸数值。
3. 不得只给单个毫秒数而不给区间、前提与取舍条件。
4. 不得在图模式下给出毫秒级具体值。
5. 不得用 `p_hist`、逐轮标记数等随 P 变化的量横向比较扫描质量。
6. 不得用图内可读的 `Mig` 值（如切换轮 76、稳态 0）反推 M：单个 M 档位上的迁移量只能支撑"迁移集中在状态切换处"这一方向结论，不构成下降曲线。

9. 若报告给出了 `smap.scan.period` / `smap.migrate.period` 建议值：每个值都落在 `strategy_config.h` 的合法范围内、满足 `M ≥ P`、挂了依据与前提、给了区间与取舍条件，并说明了外推限制（按倍数迁移而非照搬毫秒数）；M 相关结论已用固定容量口径复算（Step 4.5）。

11. 图模式下每个引用的数值都能指向 `img/<tag>/` 里**一张已入库的单格放大图**；没有对应图支撑的数值一律删除或降级为"未提供"。
12. 分片按面板行边界裁切、无面板被切断，文件名带 `rows<a>-<b>`；单格图与分片图都在图目录里，临时目录的裁切图未进入报告。
13. cycle 编号全文统一（`cycle N` = 第 N 个面板，0 起，对应 `scan_N`），未混用"第几轮/第几格"；分区图的横向位置写成"排序索引/分界比例"，没有冒充 `Page_Index`。
14. 图模式报告的环境表里，凡未随图提供的参数/进程/时序都写「未提供」，没有用操作者记忆补全。
15. 客户版：正文用白话，必要术语首次出现有极短注释（≤ 10 字），完整定义在附录 C 术语表。
16. 客户版：关键数字带参照物（小比例给"多少次里约 1 次"，大比例给绝对量，百分点差给起点与终点）。
17. 客户版：开头有"一句话结论 + 三条要点 + 建议做什么"；非专家读完后能复述结论；"这意味着"只在必要处写一句，不逐条重复。
18. 客户版：正文无代码、命令、内部路径（均在附录）；类比已标"打个比方"且未替代事实；通俗化没有放宽口径（图模式仍无精确计数，模拟仍标模拟）。

20. 核心指标表的指标名符合 Step 4.4 的固定叫法：没有口语化简称；"轮"与"周期"未混用；迁移量单位为"页（换入 + 换出）"而非"页次"；图模式指标均带"模拟 / 读图估计 / 图内标签"限定。

## 附录：采集流程（需要从零跑一遍时）

> 本节属**采集侧**操作，与报告输入无关：出报告只需要热区图；只有要把扫描数据也纳入分析（数据模式）时才需要走到这里。

```bash
# 0) 依赖（openEuler）：内核侧 gcc/make/kernel-devel，分析侧 python3-numpy/python3-matplotlib
dnf install -y gcc make kernel-devel dos2unix python3-numpy python3-matplotlib
# 1) 编译模块（源码从 Windows 拷贝过来必须先转行尾）
dos2unix hotscan_main.c && make
# 2) 起激励，记下 stdout 打印的 pid 与 base VA
gcc -O2 -Wall -Wextra -o tests/hot_region_stimulus tests/hot_region_stimulus.c
./tests/hot_region_stimulus
# 3) 采集：test_tag 决定输出目录（/tmp/<TAG>/scan_*.out），相位切换靠信号
insmod ./hotscan.ko target_pid=<PID> scan_period_ms=100 test_tag=<TAG> num_workers=4
sleep 4; kill -USR1 <PID>; sleep 4; kill -USR2 <PID>; sleep 4
rmmod hotscan                                  # 先卸载再分析，避免边写边读
# 4) 校验（相位窗口按本次激励的实际 sleep 节奏重算，见 Step 1）
cd <HS> && python3 tests/verify_hot_regions.py /tmp/<TAG> 0x<BASE_VA> \
    --phase-a 5:35 --phase-b 45:75 --idle 85:105 --max-noise 0
```

模块参数只有四个：`target_pid`、`scan_period_ms`、`test_tag`、`num_workers`。目标进程必须是宿主进程（二级 MMU 不支持），且采集前关闭 THP。

**高频采集前先降 console 日志级别**：每轮结束时的 `pr_info` 走串口 console 同步输出，会把轮次上限压到 100 Hz 量级（实测 2 GiB 目标 @2 ms：默认 41 Hz / 100 Hz，`console_loglevel=3` 后 499.97 Hz / 82.37 Hz）。采集完记得恢复原值。

## 故障排除

| 症状 | 原因 | 处理方式 |
|---|---|---|
| `Cannot set both local_ratio and local_mask_preset` | 两个都传了 | 只传 `local_ratio`（本地容量是假设值） |
| `One of local_ratio and local_mask_preset should be set` | 两个都没传 | 传 `local_ratio=0.75` 等 |
| `FileNotFoundError: No scan files match '<glob>'` | glob 路径写错、漏引号被 shell 展开、或扫描文件不在该目录 | 路径加单引号；确认目录里有 `scan_0.out` 起的连续序列 |
| 目标页索引断言失败 | base VA / page_size / 页数填错，或扫描文件与激励不是同一次运行 | 核对激励 stdout 的 `base=`，并确认 `unique_va` 覆盖完整映射区 |
| 图里中文变方框 | matplotlib 无 CJK 字体 | 图标签改英文 |
| 生成的图覆盖了既有图 | `img/<tag>` 由输入目录名推导，tag 撞名 | 把扫描文件放到本批次独立目录 |
| `plot_hot_region.png` 巨大无法查看 | 120–400 面板 × 3.5 m 高 | 按 Step 3.6 裁成 20 行分片 + 关键轮单格放大（都入库），分片判段级、单格读数值 |
| 访问标记数远小于激励触碰数 | 布尔语义（正常） | 在报告中显式说明，不是缺陷 |
| 采集轮次远低于预期频率 | 每轮 `pr_info` 经 console 同步输出，且该语句位于 `scan_running` 复位之前 | 临时降低 `console_loglevel`（实测 100 Hz→499 Hz），采集后恢复 |
| 目标进程结果恒为空 | 目标是虚机/容器内进程（二级 MMU 不支持） | 换成宿主进程采集，或声明该场景不支持 |
| 逐页统计出现整块大页 | THP 未关闭 | 激励侧 `MADV_NOHUGEPAGE`，或系统关闭 THP |
| 模块源码在 Windows 上编译失败 | CRLF 行尾 | `dos2unix` 转换后再编译 |

## 关键约定

1. **先门禁后分析**：数据质量核验不通过时不出报告。
2. **口径先声明**：每个引用数字都带上"轮次范围 × 页集合 × 是否去 warmup"。
3. **模拟与实测分离**：`local_ratio` 相关结论一律标注为策略模拟。
4. **图要配机理解释**，不要只贴图。
5. **判据事先固定**，允许"不通过"，不允许事后改判据凑结论。
6. 报告写入 `<HS>/docs/`，命名 `<批次>_analysis_<YYYY-MM-DD>.md`；图片进 `<HS>/img/`，需同步 `.gitignore` 白名单。
7. **只报告数据能支撑的**：加压命令、负载语义、真值这些外部信息拿不到就写"未提供"，用中性标签描述工况段，不靠曲线形状反推负载。
8. **参数建议必须可落地**：给出 SMAP 的 `smap.scan.period` / `smap.migrate.period` 建议值时，先核对 `strategy_config.h` 的范围与 `StrategyConfigReview()` 的 `M ≥ P` 约束，再按 Step 4.5 的链条推导，最后用"倍数 + 区间 + 取舍条件 + 外推限制"表达。
9. **lifetime 图必含**：任何热区图分析报告都要有热区生命周期图（sorted 必备、未排序推荐）。它是"热区有多宽、有没有长尾、台阶如何分布"的唯一直接证据；缺图就先补图再写报告，且补图必须遵守 Step 3.3 的资源约束（单 case、单图、`timeout` + `setsid nohup`）。
10. **大图不直接读**：逐轮/分区大图一律按 Step 3.6 分片（段级）再单格放大（轮级），两张图都进 `img/<tag>/`；报告里的轮级数值必须有对应单格图作为出处。
11. **编号口径唯一**：`cycle N` = 第 N 个面板（0 起，对应 `scan_N`）；分区图横轴是排序索引，不能当 `Page_Index` 或 VA 用。
12. **指标名固定**：核心指标表一律用 Step 4.4 的固定叫法（含单位与口径限定），口语化简称不得进报告。
